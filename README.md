# kouzi-buddy-points

WorkBuddy「Buddy 加油站」每日积分领取助手 Skill。

## 它做什么

一个**合规版**的积分提醒与打卡追踪 Skill，配合 WorkBuddy 的定时 automation 使用：

- ⏰ 每天 **09:00 主提醒** + **20:00 断签兜底提醒**
- 📅 自动记录连续打卡天数，追踪 7 / 14 / 28 天里程碑奖励
- 🛡 断签保护：提醒用「补登卡」补签（上限 4 张）
- ✅ 领取后回一句「领了」或甩截图即可打卡确认

> **合规声明**：官方积分领取入口在 WorkBuddy PC 客户端内「Buddy 加油站」活动页，规则要求**每日手动点击领取**，无开放 API、无网页版入口。
> 本 Skill **绝不**做模拟点击、不逆向内部接口、不存储任何账号凭据。它只负责提醒、记录和断签保护，最后那一下仍由你手动点击。

## 安装

将本仓库的 `SKILL.md` 放入 WorkBuddy 的 skills 目录（用户级 `~/.workbuddy/skills/kouzi-buddy-points/`）。

## 触发方式

- **定时**：由 WorkBuddy automation 每天 09:00 / 20:00 触发提醒。
- **手动**：对 WorkBuddy 说「领积分 / 签到 / 打卡 / buddy积分」。

## 积分规则速查（2026-09 核实）

| 项目 | 规则 |
|---|---|
| 每日积分 | 每期活动不同（近期 100~150 积分/天），以客户端活动页为准 |
| 积分有效期 | 自到账日起 1 个月 |
| 连续 7 天 | 2 能量 + 1 补登卡 + 1 次抽奖 |
| 连续 14 天 | +50 积分 + 3 能量 + 1 补登卡 + 1 抽奖 |
| 连续 28 天 | +150 积分 + 5 能量 + 1 补登卡 + 1 抽奖 |
| 补登卡 | 最多累计 4 张，断签可补 |
| 入口 | PC 客户端 个人中心 → Buddy 加油站 |

> 活动按「期」轮换，每期有截止时间，以客户端活动页显示为准。

## 配置参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| 提醒时间 | 09:00 / 20:00 | 由 automation rrule 控制 |
| 打卡日志 | `~/.workbuddy/memory/buddy-points-log.md` | 追加式记录 |
| 补登卡数量 | 用户口述 | 打卡确认时顺带报数 |
